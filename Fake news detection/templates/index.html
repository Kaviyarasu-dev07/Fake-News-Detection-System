📘 About FNDS AI

This system leverages Natural Language Processing (TF-IDF) and Machine Learning (Logistic Regression) to definitively classify articles as Fake or Real.

⚙️ System Mechanics

1. Securely extracts textual article data via APIs.

2. Uses TF-IDF parsing to evaluate word importance.

3. A trained ML algorithm maps probabilities based on thousands of historically verified articles.

🧠 TF-IDF Features

"Term Frequency - Inverse Document Frequency" measures word significance. By checking keyword correlations, the system identifies the vocabulary most commonly aligned with fabricated journalism.
